# 🧭 Навигация в приложении

## Главная страница `/`

Главная страница редактора BibTeX теперь включает **навигационную панель пользователя** в верхней части.

### Что показывает навигационная панель:

#### 1. Информация о пользователе
- **Аватар** - круглая иконка с первой буквой имени
- **Имя пользователя** - отображается жирным шрифтом
- **Роль** - цветной бейдж:
  - 🔴 **Администратор** (красный)
  - 🟢 **Пользователь** (зеленый)
  - 🟡 **Гость** (желтый) + время до истечения сессии

#### 2. Индикатор API ключа
Если у пользователя сохранен API ключ OpenAlex, отображается синий бейдж:
```
🔑 API ключ подключен
```

#### 3. Кнопки навигации

**Для всех авторизованных пользователей:**
- **Профиль** - переход на страницу `/profile`
- **Выйти** - выход из системы

**Дополнительно для гостей:**
- **Продлить сессию** - добавить еще 24 часа к сессии
- **Зарегистрироваться** - создать постоянный аккаунт

#### 4. Предупреждение для гостей
Если до истечения гостевой сессии осталось **менее 1 часа**, появляется желтое предупреждение:
```
⚠️ Ваша гостевая сессия истекает менее чем через час. 
Зарегистрируйтесь, чтобы сохранить данные.
```

## Страница профиля `/profile`

Страница для управления настройками пользователя.

### Разделы:

#### 1. Информация профиля
- Изменение имени
- Просмотр email (нельзя изменить)
- Просмотр роли

#### 2. API ключ OpenAlex
- Ввести новый API ключ
- Показать/скрыть текущий ключ
- Удалить ключ

#### 3. Изменение пароля
- Только для зарегистрированных пользователей (не для гостей)
- Требует текущий пароль

#### 4. Управление гостевой сессией (только для гостей)
- Оставшееся время сессии
- Кнопка "Продлить сессию"
- Кнопка "Зарегистрироваться"

---

## Админ-панель `/admin`

Доступна **только администраторам**. Включает:
- Управление типами BibTeX
- Управление полями
- Критерии кафедры

## Сценарии использования

### Сценарий 1: Новый пользователь заходит на сайт

1. Переходит на `/`
2. Если не авторизован → редирект на `/login`
3. Может:
   - Войти с существующим аккаунтом
   - Зарегистрироваться (`/register`)
   - Перейти на `/guest/login` для выбора типа входа

### Сценарий 2: Гость работает с системой

1. Переходит на `/guest/login` (GET)
2. Видит страницу с выбором типа входа
3. Нажимает "Войти как гость" (POST /guest/login.submit)
4. Попадает на главную страницу `/`
5. Видит навигационную панель с:
   - Информацией о гостевой сессии
   - Кнопками "Продлить сессию" и "Зарегистрироваться"
6. Может работать с редактором BibTeX
7. Когда сессия истекает (< 1 часа):
   - Появляется предупреждение
   - Предлагается зарегистрироваться
8. Может зарегистрироваться через `/profile/guest/register`:
   - Все данные сохраняются
   - Гость становится постоянным пользователем

### Сценарий 3: Постоянный пользователь

1. Входит через `/login`
2. Попадает на `/`
3. Видит навигационную панель с:
   - Именем и ролью
   - Индикатором API ключа (если есть)
   - Кнопками "Профиль" и "Выйти"
4. Может перейти в профиль для:
   - Изменения имени
   - Управления API ключом
   - Изменения пароля

### Сценарий 4: Администратор

1. Входит через `/login`
2. Имеет доступ к `/admin`
3. Может управлять системой через админ-панель

## Быстрые ссылки

| Ссылка | Описание | Доступ |
|--------|----------|--------|
| `/` | Главная страница редактора | Только авторизованные |
| `/profile` | Профиль пользователя | Только авторизованные |
| `/login` | Вход в систему | Все |
| `/register` | Регистрация | Все |
| `/guest/login` (GET) | Страница выбора типа входа | Все |
| `/guest/login` (POST) | Войти как гость (форма) | Все |
| `/admin` | Админ-панель | Только админы |

## Middleware защиты

### `auth`
- Требует авторизации для доступа к страницам

### `role:admin`
- Требует роль администратора
- Пример: `->middleware('role:admin')`

### `role:user`
- Требует роль пользователя
- Пример: `->middleware('role:user')`

### Автоматическая проверка гостевой сессии
- Middleware `CleanupExpiredGuests` запускается при каждом запросе
- Автоматически удаляет просроченные гостевые аккаунты
- Если гостевая сессия истекла → автоматический логаут

## Отображение роли в интерфейсе

### Цвета бейджей ролей:
- **Администратор**: Красный фон (`bg-red-100`), красный текст (`text-red-800`)
- **Пользователь**: Зеленый фон (`bg-green-100`), зеленый текст (`text-green-800`)
- **Гость**: Желтый фон (`bg-yellow-100`), желтый текст (`text-yellow-800`)

### Индикатор API ключа:
- Синий фон (`bg-blue-50`), синяя рамка (`border-blue-200`)
- Иконка 🔑 + текст "API ключ подключен"

---

## Примечания

- Все формы используют CSRF-защиту (`@csrf`)
- Маршруты выхода: `POST /logout` (Fortify)
- Гостевая сессия: 24 часа с возможностью продления
- После регистрации гость становится постоянным пользователем
